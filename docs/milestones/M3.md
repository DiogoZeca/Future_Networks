# M3 — Comandos

**Objetivo:** `/list`, `/msg <nick>`, nicks únicos, `ERROR` com códigos,
especificação escrita.

## Feito quando
- [ ] `/list` → `LIST` → `USERS`
- [ ] `/msg nick texto` → `PRIV` → `CHAT` com `private:true`
- [ ] Nick repetido → `ERROR 409`
- [ ] Restantes códigos de erro conforme `PROTOCOL.md`
- [ ] `/quit` → `QUIT`
- [ ] `PROTOCOL.md` v1.0 fechado com os outros grupos
- [ ] Cenários em `tests/interop/` a passar contra ≥ 2 servidores de outros grupos
