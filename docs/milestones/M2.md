# M2 — Vários clientes

**Objetivo:** uma thread por cliente (ou `select`/`poll`); lista partilhada
protegida por mutex; broadcast; avisos de entrada/saída.

## Feito quando
- [ ] Servidor atende N clientes em simultâneo
- [ ] Lista de clientes protegida por `pthread_mutex`
- [ ] Broadcast: copiar a lista dentro do lock, enviar fora dele
- [ ] Lock de escrita por cliente (evitar mensagens intercaladas)
- [ ] `EVENT` de entrada e saída
- [ ] Cliente com 2 threads: socket + teclado
- [ ] Teste com clientes de outro grupo
